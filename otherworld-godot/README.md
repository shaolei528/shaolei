# Otherworld Embers: isolated Godot validation

This directory is a separate Godot 4.7.2 technical validation slice for Otherworld Embers. It does not replace Abyssal Wake, the root game, multiplayer networking, or production deployments.

The current Otherworld v1.28 JavaScript source is retained separately; this slice is not a completed migration. Engine, collision, Web export, and browser checks are tracked explicitly.
