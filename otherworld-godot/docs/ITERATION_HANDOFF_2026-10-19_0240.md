# 《异界余烬》Godot 2.5D 迭代交接 · 0.3.0

## 本轮交付

在保留 0.2.1 采集/营火循环的基础上，完成一个单敌人战斗纵切片：营火点亮后唤醒一只 2 HP 的 Ashling；F 攻击扣血，Shift 闪避并获得短暂受击免疫；击败后 `ashen_shard` 以稳定 ID 进入现有背包并显示占位掉落物。玩家显示 3 点生命值，倒下后安全重生。手机 HUD 增加攻击和闪避按钮。

这一激活时机是按浏览器实测调整的：最初让敌人从开局追击，会在玩家完成余烬/营火教学循环之前频繁击倒玩家；现在的敌人只在首个营火建成后开始追踪，遭遇更清晰也可稳定验收。

- GitHub Actions：Godot 4.7.2 stable 官方引擎导入、无头运行、34 项烟雾断言、Web 导出全部通过，0 失败。
