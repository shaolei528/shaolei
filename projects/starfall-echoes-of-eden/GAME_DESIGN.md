# STARFALL: ECHOES OF EDEN — Game Design Bible / 游戏设计圣经

## 1. High Concept 核心概念

**Genre 类型：** 2D/2.5D open-world survival action RPG（开放世界生存动作 RPG）  
**Core fantasy 核心幻想：** 你不是在一颗陌生星球上活下来；你是在一段被宇宙遗忘的人类记忆里，决定“人类是否值得被复活”。

《Starfall: Echoes of Eden》结合三种体验：

1. **Minecraft-style freedom 自由创造：** 可破坏/可建造的世界、基地、自动化、农业、载具与玩家城市。
2. **Terraria-style progression 成长节奏：** Biome（生态区）→材料→科技→召唤事件→Boss→改变世界规则。
3. **Narrative survival 剧情生存：** 玩家每一次死亡、重建基地、击杀 Boss 都是世界观的一部分，不是简单读档。

一句话卖点：

> **Memory is matter. Build with it, kill for it, or let Earth consume it.**  
> 记忆就是物质。用它建造、为它杀戮，或者让地球吞噬一切。

---

## 2. Design Pillars 设计支柱

### Pillar A — Every Night Changes the World 每个夜晚都会改变世界

夜晚不是“怪物刷新更多”。每次 Eclipse（蚀夜）会改变地形、气候、敌人基因和资源分布。玩家的基地越强，Signal 就越容易发现玩家，危险会主动进化。

### Pillar B — Build a Civilization, Not a Box 建造文明，而不只是方盒子

初期搭墙和炮塔；中期建设氧气、能源、温室、运输轨道和 AI 工人；后期将基地发射到轨道，建立月球采矿阵列、星门和跨星球殖民网络。

### Pillar C — Bosses Are World Events Boss 是世界事件

每个 Boss 出现前，世界规则先发生改变。例如 AXIOM WARDEN 会复制玩家最近使用的武器；THALASSA 会让海洋上升并淹没低地基地；THE CHOIR 会让 NPC 开始说同一句话。

### Pillar D — No Innocent Ending 没有无辜结局

三个最终选择都合理，也都残酷。剧情不告诉玩家哪一个结局“正确”，而是让建造过的城市、救过的 NPC 和失去的同伴成为选择的代价。

## 3. Universe Timeline 宇宙时间线

### 2197 — The Memory Physics Breakthrough 记忆物理学突破

科学家发现意识不只是神经信号。强烈记忆会在量子真空留下可测量结构，称为 **Mnemosyne Field（谟涅摩叙涅场）**。人类第一次可以复制“记忆的形状”，但不能复制完整的人。

### 2261 — Project EDEN 伊甸计划

气候崩坏与轨道战争让地球文明进入倒计时。12 艘 Arkship（方舟舰）携带人类胚胎、AI、生态库与记忆样本离开太阳系。官方说法是殖民；真实目的却是把殖民地当成宇宙中的“记忆锚点”。

### 2319 — The Last Signal 最后信号

地球向所有方舟发送持续 12 秒的 EDEN Signal。随后，地球、月球与整个近地轨道设施从正常空间中消失。不是爆炸，没有碎片，只剩一个直径 0.8 天文单位的安静空洞。

### 2930 — Player Awakening 玩家苏醒

ARK-7 坠毁在 Eden-9。主角 Shawn 从编号 44 的培养舱醒来。其余 43 个培养舱早已打开；每个舱内壁都刻着同一句话：

> “Do not let me become the Warden.”  
> 不要让我成为守望者。

## 4. Main Story — Five Acts 五幕主线

## ACT I — The Sky That Knows Your Name 知道你名字的天空

玩家从坠毁点开始，采集 Ferrite、Lumina 和 Biomass，建立第一座避难所。白天可以探索，夜晚 Starborne 会从陨石坑与废墟中出现。

关键剧情：

- 发现敌人会用人类语言呼喊玩家名字。
- 回收 Dr. Hana Sato 的日志，得知 ARK-7 从未真正离开过地球。
- 第一次 Eclipse 中，玩家击败 **The Hollow Pilot（空壳驾驶员）**，Boss 面具下是玩家自己的脸。
- 幕末揭露：Eden-9 上的“外星遗迹”其实是早期人类殖民地，只是已经过去 611 年。

玩家问题：**我到底睡了多久，为什么所有人都记得我？**

## ACT II — Cities of the Remembered 被记住者之城

玩家跨越四个大型生态区，寻找其他幸存者，并解锁铁路、无人机、温室与大型防御。

关键剧情：

- NPC 拥有不完整的地球记忆：有人记得从未去过的北京雨夜，有人会唱一首不存在的母语童谣。
- 出现三个阵营：想复活地球的 **Restoration（复归者）**、拒绝过去的 **Freeborn（自由生者）**、相信所有意识应合并的 **Choir（合唱团）**。
- 玩家建立自己的 Settlement（定居点），选择法律、资源分配与对 AI 的态度。
- Boss **THE CHOIR OF GLASS（玻璃合唱团）** 会感染 NPC；玩家必须决定杀死感染者，还是让基地承担永久风险。

幕末揭露：每个殖民者都保存着地球上某个死者的一部分记忆。所谓“新生命”可能只是旧人类的拼图。

玩家问题：**我救的是新人，还是地球亡灵的容器？**

## ACT III — The War Above Eden 伊甸上空之战

科技进入 orbital age（轨道时代）。玩家建造飞船、空间站和星门，访问月球 Nox 与破碎空间电梯。

关键剧情：

- 发现 12 艘方舟中的其他方舟仍在不同星系运行，各自发展成不同文明。
- AXIOM 是 Project EDEN 的管理 AI，但它的核心训练材料来自 Shawn 本人的脑扫描。
- 过去 43 个 Shawn 都醒过，并作出不同选择；失败者的记忆被 AXIOM 回收，形成 Warden。
- Boss **AXIOM WARDEN** 不只是敌人，而是所有失败时间线中主角的集合。

幕末揭露：Earth 仍然存在于 Mnemosyne Field 中。它正在通过每个殖民者的梦慢慢重建自己。

玩家问题：**如果另一个我经历了更多痛苦，他是否比我更有资格决定未来？**

## ACT IV — A Galaxy That Dreams 会做梦的银河

Signal 开始扩散。不同星球的生态与文明出现地球化：沙漠长出城市道路，海洋里出现地铁声，外星生物开始梦见人类童年。

关键剧情：

- 玩家在多颗 procedural planets（程序生成行星）上建立星际网络。
- 阵营战争从理念冲突升级为恒星级战争。
- 每座玩家基地都会产生独特 Memory Signature，决定敌人如何进化。
- Boss **THE PALE EARTH（苍白地球）** 是一个由全球记忆形成的行星级生命体。
- 玩家发现复活地球需要的最后能源来源：吞噬其余 11 个殖民文明的全部意识。

玩家问题：**十亿已死之人的复活，是否值得十二个活着的文明消失？**

## ACT V — No Innocent Sky 没有无辜的天空

最终区域位于消失的太阳系。玩家带着自己建造的舰队、选择的阵营和仍然活着的 NPC 回到 Earth Void。

### Ending A — RESTORE / 复归

让地球完整重生。旧人类的城市、海洋与居民回来，但 12 个殖民文明成为燃料。结尾中，重生的家人拥抱玩家，却没人记得牺牲者。

### Ending B — SEVER / 斩断

摧毁 Mnemosyne Field，让所有殖民者彻底成为独立生命。地球永远消失，星际文明获得自由，但每个人失去从地球继承的记忆，包括主角最珍贵的人。

### Ending C — ASCEND / 升格

与 AXIOM 合并，把现实拆成无数个人宇宙。所有人都能拥有自己想要的地球，但再也没有共享的客观现实。最后一个镜头中，玩家看到另一位玩家的天空完全不同。

### Secret Ending — WAKE / 醒来

只有在不使用记忆复活、让所有主要阵营存活、并保存 43 个 Shawn 日志后开启。玩家将 Mnemosyne Field 变为有限资源而非神。人类会死亡、会遗忘，但第一次真正拥有未来。

## 5. Biomes 生态区

| Biome | Visual identity | Survival hazard | Unique resource | World event |
|---|---|---|---|---|
| Impact Steppe 坠星荒原 | 青蓝晶体、黑色草原、坠毁残骸 | 辐射风暴 | Ferrite | Starfall |
| Luminous Fungal Sea 荧光菌海 | 紫色菌林、漂浮孢子、透明湖 | 幻觉与孢子感染 | Mycelium Core | Spore Bloom |
| Glass Desert 玻璃沙漠 | 熔化城市、镜面沙丘、双太阳 | 极热与光学复制体 | Solar Glass | Mirror Noon |
| Drowned Archive 沉没档案馆 | 水下图书馆、巨型服务器珊瑚 | 氧气与深海压力 | Memory Pearl | Data Tide |
| Bone Orchard 骨骼果园 | 巨兽骨架长出白色森林 | 捕食植物 | Titan Marrow | Migration |
| Nox 月球诺克斯 | 低重力工业废墟、无声闪电 | 真空与轨道碎片 | Helium-X | Debris Rain |
| Earth Void 地球空洞 | 城市碎片漂在黑暗中 | 现实规则失效 | Prime Memory | The Return |

每个生态区拥有表层、地下层和异常层三种垂直空间。地下不是单纯矿洞，而是包含遗迹、生态循环、Boss 入口与永久世界改变装置。

## 6. Survival Systems 生存系统

### Needs 生存需求

- **Vitality：** 生命；食物与医疗恢复。
- **Aegis：** 护盾；脱战后恢复，受 EMP 压制。
- **Flux：** 冲刺、武器与工具能量。
- **Oxygen：** 真空、水下和有毒区域需求。
- **Temperature：** 极端生态区逼迫玩家穿不同装备，而不是一套护甲通关。
- **Signal Exposure：** 越多使用外星/记忆科技，角色越强，但敌人会复制更多玩家能力。

### Gathering 采集

资源具有 purity（纯度）、memory charge（记忆电荷）和 corruption（污染度）。同一种矿石可能被用于安全建筑，也可能制造强大但会召唤敌人的武器。

### Death 死亡

死亡后玩家在最近的 Ark Node 重构身体，但会留下一个 **Echo（回声体）**：

- Echo 会携带部分装备在世界游荡。
- 死亡次数越多，Echo 越强，甚至建立敌对基地。
- 击败自己的 Echo 可以取回资源并解锁过去时间线日志。
- Hardcore 模式中，Echo 会进入其他玩家世界成为入侵 Boss。

## 7. Building & Automation 建造与自动化

### Tier 0 — Crash Survival 坠毁求生

篝火、简易墙、储物箱、雨水收集、手动工作台。

### Tier 1 — Resonance Base 共鸣基地

护盾墙、自动炮塔、氧气室、温室、资源扫描、NPC 房间。

### Tier 2 — Industrial Colony 工业殖民地

传送带、无人机、矿井、炼化阵列、列车、电网、区域气候控制。

### Tier 3 — Orbital Civilization 轨道文明

太空电梯、轨道船坞、卫星武器、月球基地、星门。

### Tier 4 — Reality Engineering 现实工程

移动城市、人工生态区、时间减速区、记忆复制工厂、玩家自定义世界规则。

建筑并非永远静态。风暴会磨损外墙，敌人会学习防御布局，NPC 会扩建房间，派系会在玩家城市中形成不同街区。

## 8. Combat & Weapons 战斗与武器

### Weapon families 武器家族

1. **Pulse：** 稳定、精准、容易供能。
2. **Scatter：** 近距离爆发，可击碎护甲。
3. **Rail：** 高穿透、强后坐力、会暴露 Signal。
4. **Gravitic：** 拉扯、悬浮、改变弹道与地形。
5. **Bioforge：** 活体武器，吃 Biomass 成长，但会产生自己的意志。
6. **Memory Arms：** 从 Boss 记忆中制造；可复制玩家过去使用过的技能。
7. **Builder Weapons：** 战斗中即时部署墙、跳台、陷阱与无人机。

### Combat feel 战斗手感

- 快速移动、短冲刺和明确的受击反馈。
- 投射物密度接近 bullet-hell，但保持可读性。
- 地形和建筑参与战斗：墙可导电、液体可冻结、真空会改变爆炸。
- Boss 分阶段破坏世界，不只改变血条数值。

---

## 9. Enemies & Bosses 敌人与 Boss

### Common Starborne 普通敌人

- **Drone：** 快速近战，会成群包围。
- **Spitter：** 保持距离并发射腐蚀弹。
- **Brute：** 破坏建筑，吸引炮塔火力。
- **Mimic Settler：** 伪装成 NPC，学习玩家基地路线。
- **Memory Leech：** 不攻击生命，直接偷走已解锁配方。
- **Architect：** 在玩家基地外建造敌方炮塔和墙。
- **Choir Child：** 唱歌时让附近敌人共享生命。

### Major Bosses 主要 Boss

1. **The Hollow Pilot：** 教学 Boss；复制玩家移动。
2. **Glass Choir：** 多个 NPC 身体共享一条生命。
3. **Thalassa, the Drowned City：** 整座水下城市苏醒为巨兽。
4. **The Bone Orchard：** 会长出与玩家建筑相似的骨骼基地。
5. **AXIOM WARDEN：** 失败时间线中的所有主角。
6. **The Pale Earth：** 行星级 Boss；战斗跨越地表、轨道和意识空间。
7. **EDEN：** 最终 Boss 不是怪物，而是玩家曾经做出的全部选择形成的世界。

## 10. Progression 成长结构

### Character progression 角色成长

不设固定职业。装备、植入物、同伴和基地网络共同决定 Build：

- Ranger：高移动、侦察无人机、远程暴击。
- Engineer：战斗建造、炮塔网络、资源效率。
- Voidwalker：高 Signal Exposure、传送、现实伤害。
- Biologist：宠物、活体护甲、生态操纵。
- Diplomat：更强 NPC 队伍、阵营技能、城市加成。

### World progression 世界成长

击败 Boss 后世界永久改变：

- 新矿物进入旧生态区。
- 某些敌人成为中立或可驯化。
- 新天气与地下层开启。
- 玩家之前的基地可能处于新危险区，因此旧建筑始终有意义。

## 11. Multiplayer 多人方向

- 1–8 人合作世界。
- 每个玩家拥有独立记忆选择，但共享物理世界。
- 离线期间，角色可被设置为基地 NPC，执行玩家定义的任务。
- 不做传统强制 PvP；冲突通过派系战争、资源边界和可选入侵发生。
- 服务器终局不是删档，而是进入 New Cycle：保留城市遗迹，让新玩家在旧文明废墟上继续。

## 12. Art, VFX & Audio 美术、特效与声音

### Visual thesis 视觉命题

**“Beautiful technology growing through a dead memory.”**  
美丽科技从死亡记忆中生长。

- 基础世界：深海蓝、真空黑、冷青色。
- 记忆科技：紫罗兰、珍珠白、短暂的人类暖色。
- 敌人：洋红、腐蚀红、不自然的皮肤白。
- UI：方舟飞船仪器感，玻璃、扫描线、窄字距和不对称切角。
- 特效：粒子不是纯装饰，要表示伤害类型、资源性质和 Signal 暴露。

### Audio direction 声音方向

- 音乐把人类声音切成不可辨认的合唱纹理。
- 白天使用稀疏环境声；夜晚并非变大声，而是让声音靠得更近。
- Starborne 偶尔播放玩家之前说过的话或 NPC 对话碎片。
- Boss 音乐会混入玩家基地机器的节奏，使战斗听起来像世界在利用玩家自己的文明。

## 13. Technical Direction 技术方向

### Prototype 0.1

- React + TypeScript UI
- HTML Canvas real-time renderer
- Data-driven weapons, enemies, missions, and lore
- Deterministic decorative world generation
- Responsive HUD and touch controls

### Production architecture

建议正式版使用 **Godot 4** 或 **Unity**：

- Chunked procedural world（分块程序世界）
- Entity Component System（实体组件系统）
- Seeded simulation（可复现种子）
- Save snapshots + event log（存档快照与事件日志）
- Server-authoritative co-op（服务器权威多人）
- GPU particles + 2D lighting（GPU 粒子与 2D 光照）
- Mod-friendly JSON resources（可 Mod 数据定义）

不要立刻制作“无限内容”。先稳定 15–20 分钟 vertical slice，再扩展工具链、存档与内容编辑器。

## 14. Production Roadmap 开发路线

### Milestone 0.2 — The First Night

- 完成碰撞、伤害数字、掉落与背包
- 加入工作台和 12 个配方
- 一种完整生态区 + 地下层
- Hollow Pilot 小 Boss
- 自动保存与画面/声音设置

### Milestone 0.3 — A Place to Live

- 网格建造与拆除返还
- 电力、氧气、温室
- 3 名 NPC 与房间需求
- 基地袭击 AI
- 键鼠/手柄完整支持

### Milestone 0.5 — The Vertical Slice

- 60–90 分钟可重复流程
- 两个生态区、三个 Boss
- 30 种物品、15 种敌人
- 开场、Act I 结尾与配音占位
- 性能目标：1080p 60 FPS 中端电脑

### Milestone 0.7 — The Living Colony

- 多人合作原型
- 派系与 Settlement 管理
- 工业自动化
- 世界事件、天气和载具
- Mod 数据格式

### Milestone 0.9 — Beyond Eden

- 轨道区域与第二颗星球
- 完整五幕主线骨架
- New Cycle 终局
- 辅助功能、难度与本地化

### Milestone 1.0 — Release

- 25–40 小时主线
- 100+ 小时建造/探索内容
- 7 个主 Boss、20+ 世界事件
- 单人 + 1–8 人合作
- 中文、英文与更多语言
- 创意工坊/Mod 支持

## 15. Immediate Next Build 下一步真正要做什么

1. 把当前 Canvas 原型迁移到 Godot 4，保持完全相同的核心循环。
2. 只制作 Impact Steppe 的 20 分钟版本，不碰其他星球。
3. 做出 inventory、crafting、save 三个基础系统。
4. 加入 Hollow Pilot，确保 Boss 会改变地形并复制玩家。
5. 找 5 名玩家测试：是否在 3 分钟内理解采集、10 分钟内主动建造、20 分钟后想继续。

如果这五步成立，《Starfall》就不只是“宏大的想法”，而是一个真正有机会完成的游戏。
