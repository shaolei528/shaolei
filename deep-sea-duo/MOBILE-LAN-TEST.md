# 《深海搭档 / Deep Sea Duo》两台手机真实联机验收流程

当前正常玩家只使用 **6 位房间码**，不需要复制 WebRTC Offer / Answer 长文本。

网络设计：

1. 正式 Netlify 部署使用 Deep Sea Duo 自己的同源 `/room` API；
2. 当前静态试玩链接自动使用 `ntfy.sh` 公共 topic，只交换 Offer / Answer；
3. 真正游戏数据始终通过 WebRTC DataChannel 点对点传输；
4. 房主始终是唯一权威模拟；
5. 不修改、不复用《ABYSSAL WAKE》的 Cloudflare Worker；正常配对也不依赖 Supabase。

## 0. 准备

- 手机 A：房主（Host）
- 手机 B：加入者（Guest）
- iPhone / iPad 推荐 Safari，Android 推荐 Chrome
- 两台手机横屏

## 1. 网络

两台手机连接同一个 Wi‑Fi，或手机 A 开热点、手机 B 连接 A 的热点。自动 6 位码配对需要短暂互联网访问信令服务；WebRTC 建立后，移动、攻击、怪物、Boss 等实时游戏 packet 不经过信令服务。

测试时建议关闭 VPN / 代理 / iCloud Private Relay，减少额外变量。

## 2. 确认审计版

两台手机必须打开同一个 HTTPS **固定 commit** 版本，并确认大厅底部显示：

`AUDIT-A1`

如果显示：

`BOOT`

说明 HTML 打开了，但 JavaScript runtime 没有成功启动。此时不要继续测试房间码，直接记录为 **startup failure**。

如果显示其它旧 build 标识，也不要继续测试。

## 3. 手机 A 创建房间

1. 点 **创建房间**。
2. 页面显示真正的 **6 位数字**。
3. 把这 6 位数字告诉朋友。
4. 保持页面打开。

## 4. 手机 B 加入

1. 点 **加入房间**。
2. 输入 A 的 6 位数字。
3. 点 **连接房间**。
4. 页面自动交换 Offer / Answer。
5. 两边显示 **局域网直连成功** 后进入游戏。

如果 WebRTC 迟迟没有建立，当前版本会在有限时间内明确失败并关闭旧 attempt，不应永久卡在“正在建立玩家连接”。

## 5. 核心可玩性 Gate

连接成功后先做这组最短 smoke，不通过就不要继续长测：

1. **1 秒内左右开始出现第一批敌人**；
2. A 左侧滑动，A 自己必须移动，B 也必须看到；
3. B 左侧滑动，B 自己必须移动，A 也必须看到；
4. 双方右侧拖动都能发射水弹；
5. 双方都能使用冲刺；
6. 世界不是静止背景：敌人会追人，水流/环境和掉落会继续更新。

任一项失败都记录为 **FAIL**，并截完整画面和 build 标识。

## 6. 双人同步验收

继续确认：

- 怪物受击、死亡结果一致；
- 两名玩家生命、经验、升级各自独立；
- 已死亡玩家不能继续射击、吃经验或捡治疗道具；
- 食物、环境、掉落没有长期分叉；
- 两边 Boss 血量、蓄力、冲刺、死亡和奖励一致；
- Boss 在地图边缘死亡时奖励仍应生成在可玩区域内；
- 中英切换、声音开关不影响网络。

## 7. 重连 / 重开回归

至少额外做一次：

1. 返回大厅；
2. 房主重新创建新房间；
3. 加入者重新输入新的 6 位码；
4. 再次连接成功；
5. 确认人物、敌人、移动继续正常。

这一步专门验证旧 snapshot tick / input / upgrade 状态不会污染下一局。

## 8. 正式通过标准

连续玩至少 **10 分钟**：

- 双方持续看到对方移动；
- 双方射击和冲刺都能被另一端看到；
- 敌人、食物、Boss、生命值没有持续性分叉；
- 无页面崩溃、永久冻结或持续不同步；
- 手机 UI 不被刘海 / Dynamic Island / 圆角遮挡关键按钮；
- 完成一次断开后新房间重连仍正常。

全部满足后才记录为 **PHYSICAL PASS**。

## 9. 如果仍然失败

截一张同时包含：

- 完整错误文字；
- 6 位房间码区域（如果仍在大厅）；
- 页面底部 build 标识；
- 如果已进入游戏，尽量同时拍到双方手机画面。

诊断原则：

- `BOOT`：runtime/startup 问题；
- `N1-N5`：静态试玩 ntfy 信令步骤；
- `W1-W3`：WebRTC 步骤；
- 显示“局域网直连成功”但不能移动/不刷敌：game-session / input / simulation integration 回归。

## 10. 高级手动模式

大厅底部仍保留 **“高级备用：手动局域网连接”**。这是维护/故障排查用途，不是正常玩家流程。
