# 深海搭档 / Deep Sea Duo

移动端双人海底合作生存游戏。当前 checkpoint 是可本地试玩的战斗核心：自由移动、拖动瞄准水弹、冲刺、三类敌人、敌人掉落食物、个人升级、环境危险、鲨鱼 Boss，以及护盾/治疗/清场海浪三种稀有道具。

## 模块边界

- `src/game/`: 无 DOM 的游戏规则、实体和数学逻辑。
- `src/game/enemies.js`: 敌人类型与行为，独立于生成和渲染。
- `src/game/environment.js`: 珊瑚、海流、水母与碰撞规则。
- `src/game/boss.js`: 鲨鱼首领状态机、冲刺预警与奖励掉落。
- `src/game/powerups.js`: 稀有道具的生成、效果和持续时间。
- `src/network/`: 纯 WebRTC 局域网直连层；只传输入与主机快照，不包含游戏规则。

## 局域网联机计划

房主手机运行唯一的权威模拟；加入者仅发送输入，接收主机快照。没有公共游戏服务器和 Supabase。当前适配器使用一次性的手动连接码交换，下一步将接入房间界面与双人实体同步。
- `src/ui/`: HUD 与升级选择界面。
- `src/game/renderer.js`: Canvas 渲染层，不改变游戏规则。
- 后续 `src/network/`: 独立的房间、WebRTC 与状态同步层。

## 本地运行

使用任何静态文件服务器在项目根目录运行，例如 `npx serve .`。触屏：左半边移动，右半边按住拖动瞄准，右下角冲刺。
