# ABYSSAL WAKE — 两位 A+ 长期工作说明

**日期：**2026-10-04（Asia/Rangoon）  
**状态：**工作委派草案 / 等用户复制给两位协作者  
**主目标：**正式游戏的全局高画质翻新；采用已选定、玩家觉得玩法方向可接受的 3/4 斜俯视，但当前原型的画面质量不合格。旧 V21 可以逐步退役，不把旧美术强行当成终点。

两位并行，但不要同时写同一文件。A+1 先给出每类资源尺寸、像素密度和锚点的合同提案；A+2 同时提供 3/4 渲染所需的运行时尺寸、地面格、角色脚点和缩放合同。主协调者把两边合同对齐后再冻结。冻结前 A+1 可做小样，不要批量按未确认规格画完整图集；A+2 可用现有图集或灰盒验证真实游戏状态和 3/4 坐标映射。

## 共同必须遵守

- 先读仓库 `AGENTS.md`、连续性 Skill、项目章程/状态、`ART_BIBLE.md`、`MODULE_MAP.md` 和相关合同；核实 branch/HEAD/status。现在工作区有许多来源未知的脏改动，不能覆盖、重置或把别人的工作算成自己的。
- 用户确认：3/4 页面的**玩法/镜头方向可以继续**，但其**画质尚未通过**。它不是第二款游戏目标；最终 successor 必须继续承接原项目的世界、角色、营地、道具、敌人、循环和多人定位。
- 目标是完整风格系统：Modern High-Detail Pixel Art，硬边、细节成组、材质丰富、实际分辨率清楚。桌面和手机显示后如模糊、粗马赛克、比例错或丢可读细节，标 **REVISE / BLOCKED**。
- 用户允许 V21 逐步退出。解释为**新 successor 替代并通过验收后，可清理经依赖审计确认已弃用的 V21 文件**。不得先删旧入口、仍在用的模块、回滚材料，或工作区来源未知的用户/并行 agent 文件。
- 图像不决定碰撞、伤害、AI、掉落、联机、存档、任务或交互。网络层不擅自变成世界权威。概念图只提取原创方向，不直接当可复制生产素材。
- 每次交付附带 Bug / 回归审查和证据标签：CONFIRMED / SUSPECTED / UNKNOWN。区分源代码检查、测试、桌面浏览器、手机尺寸、真实触屏和双客户端证据。
- 不进公网 Relay 或共享房间；不部署、合并、推送。素材保持候选，除非完成全部 gate 并由用户确认提升正式。

## 交接节奏和接口

1. A+1 输出：实际资源使用表 + 一页视觉规范 + 建议的地面/角色/道具规格。
2. A+2 输出：V21 → successor 的渲染/相机实施图 + 3/4 坐标/层序/缩放合同 + Bug 风险与测试矩阵。
3. 主协调者比对两套合同，发一份冻结版给两方；尺寸或锚点有冲突时先解决，不让美术和渲染各自假设。
4. 并行制作：A+1 在独立候选路径做一组完整 SafeCamp 场景资源；A+2 在独立 successor 路径集成真实世界/角色/营地数据与 3/4 渲染，并验证旧玩法/输入边界。
5. 汇合评审：至少审阅原图、场景 native size、1280×720、390×844；逐项审接缝、缩放、轮廓密度、角色比例、遮挡、HUD/触控、安全 fallback 与 Bug 回归。
6. 用户确认后再逐区扩展；新版本达到替换条件后才制定 V21 退役清单。
