# ABYSSAL WAKE — 统一视觉执行卡 V2

**状态：DRAFT / ART DIRECTION REVIEW / NOT PRODUCTION / 接口未冻结**  
**主责：Rendering & Art** · **协作：World & Terrain、Home & Building、Combat & Creatures、UI & Input、Integration & QA**

## 画面承诺

用原创的 Modern High-Detail Pixel Art，把熟悉的海岸日常逐步引向宇宙恐怖。固定采用宽松、易读的 3/4 斜俯视；地面、建筑立面、角色脚点服从同一斜俯空间。HOME 有人住过、能备战、容易认路；OUTSIDE 更冷、更湿、更危险，但始终看得出资源、威胁、目标和回家方向。概念参考只提取明暗与情绪，不复刻其人物、地图、建筑、UI 或文字。

## 可评审的像素规则（候选值，待项目接口确认）

| 项目 | 执行基准 |
|---|---|
| 投影与比例 | 以 `64×64` world-unit 地格投成 `64×32` 可视菱形作为评审假设。候选角色帧 `32×48`，约半格宽、1.5 个菱形高；脚底中点对地面接触点。建筑按自然足迹原生绘制，不硬塞方格。均不是已冻结的 source/display mapping。 |
| 轮廓与像素簇 | 角色及小物件以约 1px 深色有色轮廓稳住剪影，受光边可断开；环境不描整片黑边。先用 3–8px 连贯色簇做大体面，再用 1–2px 缝隙、磨损与眼神高光点题。禁止均匀噪点、柔化边缘、非整数拉伸和为凑尺寸重采样。 |
| HOME 色板与材质 ramp | 草影→草面→受光叶簇：`#465F4A → #617C58 → #89927A`；木影→木面→板沿：`#513E31 → #806044 → #A9814D`；湿沙影→干沙→贝壳亮面：`#947C59 → #C4A575 → #E1BE96`；深水→近岸水→波光：`#244B56 → #315E69 → #577D78`。炉火 `#F3C36F` 做暖色焦点，环境阴影偏冷绿灰。它们从本轮场景候选的颜色延伸，尚非生产色票。 |
| OUTSIDE 色板与材质 ramp | 湿石影→石面→冷光边：`#444C4E → #747D79 → #A1ABA4`；湿地影→苔面→稀疏草光：`#3D5750 → #728276 → #A1A083`；海水沿用 HOME ramp 的深水与近岸色，靠水面反光和岸缘分层。锈蚀提示 `#9B5145`；异常用幽青 `#8FB5AE`，极少量暗紫 `#79658A` 只落在异常焦点。危险随地点/进程增强，不全屏紫染。OUTSIDE ramp 是新提案色，须和环境参考及实际画面一起复核。 |
| 色阶预检 | 按 sRGB 线性相对亮度粗查三级次序；草、木、沙、石等材质从影到面至少提升约 `0.07`，面到高光至少提升约 `0.06`。近岸水色可放宽影面差至约 `0.035`，但须同时用冷暖色相、岸缘亮纹和断续泡沫读出边界。它是避免灰阶糊成一片的绘制筛查值，不是 WCAG 对比度、可访问性结论或最终显示保证；仍须看原生色簇和两种目标 viewport。 |
| 光照、材质、密度 | 主光暂定左上；面向光源的体面偏暖、背光面偏冷，地面接触阴影落向右下。木有板缝/端面、石有大裂面、布有受力折线、金属有窄亮边、水有成组水平反光。安静地表留负空间；营火、门口、交互点及威胁聚焦处增加细节。 |
| UI | 延续木、旧铜、海雾玻璃与纸张质感；文字和图标用少量明确色阶，在世界画面上保持更高对比。桌面与窄屏分别排版并留触控/安全边距；概念 UI 不代表已有功能。 |

## 五种体验原则如何进入美术

- **Crashlands：** 怪物体态、起手意图、受击闪色/击退方向分层易读，命中瞬间有清楚焦点。
- **Terraria：** POI 轮廓和可发现物资形成远近层次；装备门槛只用来组织可视线索，不凭美术宣称新规则。
- **Minecraft：** SafeCamp 的个性来自已支持的摆放、升级与使用痕迹；不把自由建造当成现有功能。
- **Don't Starve：** 离开暖色营地后，以雾、湿冷地表、稀疏光源与威胁剪影让风险可读，仍保留返家导航。
- **Stardew Valley：** Guide、休息点、工作台和储物围绕日常动线组织；只表现已有互动，不虚构 NPC 日程或关系系统。

## 验收与当前限制

每组先在原生像素尺寸画完整相邻场景，再检查 1×、整数最近邻预览、透明边缘、接缝重复、脚点/足迹与游戏内比例。美术不得定义碰撞、交互、掉落或联机结果。候选一律标注 **DRAFT / DEV ART PREVIEW / NOT PRODUCTION**；没有真实 successor 的 `1280×720` 和 `390×844` 画面检查，不给通过结论。

当前 SafeCamp 候选使用上述色板的一部分，但尺寸、anchor、像素 viewport、显示缩放、遮挡与 alpha 合成仍待工程负责人和主协调者冻结。此卡用于统一评审语言，不是批量绘制授权或 production contract；冻结前只可继续修订隔离的 SafeCamp 场景板。
