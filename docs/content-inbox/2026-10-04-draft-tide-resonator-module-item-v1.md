# DRAFT — 潮汐谐振器（原创探索工具）

**状态：DRAFT / NOT IMPLEMENTED / 等待用户决定是否保留**  
**类型：**可携带/可制作的探索工具概念，不是已存在物品或当前 V21 功能。  
**设计目的：**给玩家一种可读但不剧透的办法，在陌生沿海废墟中判断深渊异常大致方向与强弱，让“出发前准备”和“路上观察”比单纯追任务标记更有参与感。

## 1. 一句话体验

修复一台旧海事无线电后，它偶尔会听见**不属于电台的潮汐节律**。玩家靠近异常区域时，谐振器以细微的像素灯格、指针偏摆和短音脉冲提示“这里有东西”，但它不说是什么，也不给精确坐标。

## 2. 如何吸收五款参考体验

- **Crashlands：**工具反馈短促易懂；玩家使用后知道发生了什么，而不是只见一个复杂数值面板。
- **Terraria：**信号让玩家愿意偏离主路去发现 POI 或线索，但不会直接把秘密地图摊开。
- **Minecraft：**玩家带着自己准备的工具出门，工具是个人装备选择，不是自动推进剧情。
- **Don't Starve Together：**信号作为出行风险预告，帮助队伍决定准备、绕行或继续深入；它不是精确危险探测器。
- **Stardew Valley：**设备可能来自 HOME 的维修/居民请求，使用后带回可讨论的发现，让生活与探索互相连接。

这些只是一组设计原则，不照搬任何参考游戏的道具、地图、音效或能力。

## 3. 建议的第一版规则（仍待审）

- 玩家在 HOME 修复/制作后携带它；启动后只显示模糊方向与三级强度反馈，例如微弱静电、间歇脉冲、失真的持续回响。
- 反馈只基于当前模块已经确认的异常/POI 数据；不自行生成世界事实、不标出隐藏物准确坐标、不揭示怪物/奖励/任务结局。
- 靠近异常会增强提示，离开会减弱；在普通城市区域保持安静。应给玩家一个关掉或收起声音反馈的选项。
- 设备第一次指向异常后，仍需玩家亲自接近、观察或互动才会发现地点/线索。谐振器不自动完成探索、任务或搜刮。
- 首个版本建议作为**探索/表现工具**，不造成伤害、不改变怪物 AI、不恢复资源、不改世界/网络权威；多人可见性暂不纳入首切片，先由用户和 Network owner 单独决定。
- 是否消耗电池/材料、是否有次数/冷却、是否需要 NPC 解锁暂不定数值。先做无惩罚原型评估是否有趣，再由玩家体验决定是否增加成本。

## 4. 模块负责人和接口

| 模块 | 责任 |
|---|---|
| Items / Inventory | 物品 ID、玩家是否携带、装备/收起状态；未来若有电池/次数则唯一持有数量 |
| Crafting / HOME | 修理或制作配方、工作台位置和解锁条件 |
| World / POI / Exploration（主责玩法接口） | 提供已存在异常信号的只读快照/查询；负责真实地点是否被发现 |
| Rendering / Animation | 绘制设备、清楚的灯格/指针反馈、角色手持表现；不改变信号或世界状态 |
| Audio / Feel | 三级脉冲和方向提示音；不盖住战斗音效，遵守静音/音量设置 |
| UI / Input | 装备/启用/收起命令和强度辅助显示；键鼠与触控共用命令，不抢移动/攻击输入 |
| Quest / NPC（以后可选） | 提供修复委托或故事语境；不能持有设备库存或伪造 POI 发现 |
| Network / Save | 只有批准多人可见性或跨重进持久性后才设计适配器；此概念本身不授权改 Relay 或存档合同 |

如果未来实施，先让 World owner 定义只读信号数据的范围，再让 Item 发起查询、表现层渲染结果。接口名称、世界距离、刷新频率、持久范围和多人规则都要先核对实际项目架构，不可从本概念卡推断现成 API。

## 5. 高画质像素美术方向

**造型：**掌心大小的耐盐蚀海事测深仪与便携收音机混合体；粗磨砂深青绿外壳、黄铜修补片、旧海图刻度、一个清亮但克制的青白色谐振灯格。外壳有现实城市维修痕迹，深渊异常只在信号增强时出现轻微不对称色偏，不铺满紫色触须。

**图标与动作候选：**一张正面物品图标；角色持握的朝向版本；默认、弱信号、强信号三种清晰状态；启动/停止短动画；可选轻微指针摆动。重要轮廓要能在真实背包格子尺寸下一眼读懂，不能靠细碎噪点或外发光撑辨识度。

**给美术 AI 的概念提示草稿：**

```text
为原创游戏 ABYSSAL WAKE 设计一个“潮汐谐振器”像素美术概念：现代沿海城市废墟中由居民修复的掌上旧海事探测器/便携收音机，深青绿色磨砂金属外壳、黄铜补片、少量磨损划痕、可读刻度、一个克制的青白像素灯格。Modern High-Detail Pixel Art，清晰有设计感的像素簇，3/4 斜俯视游戏方向兼容，轮廓在实际小图标尺寸仍清楚，干净透明背景；另给出弱信号与强信号两种小幅、可读状态变化。不要照片质感、绘画笔刷、抗锯齿模糊、噪点、粗糙大马赛克、整片紫色触须、文字/logo、复杂背景或伪造游戏截图。请先交单件源概念并标明画布尺寸、像素密度、锚点和状态帧设计建议，不要自行裁切/缩放到未知素材合同。
```

提示词只是生成起点。实际画布尺寸与动画帧布局必须在检查目标物品 UI、现行 renderer 和 art contract 后才能确定；概念原图要经过透明边缘、清晰缩放、桌面/手机实际尺寸与运行画面对比验收后才能考虑接入。

## 6. 风险与验收问题

保留候选前需要先回答：

1. 现有世界里有哪些**确实存在**且值得被提示的异常信号？如果没有，本工具不能靠编造位置来显得有用。
2. 玩家是否仍需观察、走近和互动才能得到真正发现？提示是否既不太模糊到没用，也不精确到取代地图探索？
3. 信号提示会不会和战斗 telegraph、NPC 对话、重要环境音打架？手机是否能在不看小字的情况下理解？
4. 全部信号是否由 World/POI owner 提供；玩家本地表现是否不影响多人权威/任务奖励？
5. 实际背包图标尺寸、像素比例、光效与角色手持画面是否锐利、统一？

**建议验收：**一次走到无异常区域应保持安静；接近一个真实异常后反馈按强度合理变化；收起后无提示声/视觉残影；设备不能替代发现、战斗、掉落或任务判定；音效清楚且不过载；桌面和手机原生显示都能识别状态。未达到实机证据的部分标 UNKNOWN。
