## V21 object draw order and fallback summary

`modules/render/base-renderer.js:4` draws ground → camp → resources → mobs → remotes → local player → lighting. Some later wrappers add Guide, hit feedback, weapon presentation and awakening props/FX. This grouped pass order means the art contract cannot assume one universal depth order for V21. Actor missing-image fallback is weaker than resource/mob fallback; terrain has a legacy draw path. These differences are engineering presentation behavior, not art-file defects.

## Art disposition key

- **KEEP:** current gameplay/runtime visual remains as compatibility fallback; retain its source and semantics.
- **REPAINT:** replace presentation with original high-detail pixel art only after source dimensions, density, anchor and display contract are signed and dual-view reviewed.
- **REPLACE:** an existing asset class does not express a distinct visual identity (Guide currently reuses player frame); candidate needs a separately readable successor treatment.
- **WAIT:** preview-only or contract-dependent material with no production approval; keep isolated.

## Five-game experience relevance

This inventory supports one connected loop rather than five separate feature queues: readable player/monster/FX classes serve Crashlands combat feedback; the nine-biome map/terrain serve Terraria-like orientation and discovery cues; camp props serve Minecraft-like home identity; terrain/lighting and readable threat markers serve Don't Starve-like legible pressure; the Guide and SafeCamp clusters serve Stardew-like return warmth. These are presentation goals only. Existing images do not prove free building, equipment gates, NPC schedule/relationship systems, or complete expedition return progression.
